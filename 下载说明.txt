PLaMo 的 Q4_K_M 和 Q2_K 已拆成两个独立包，按需分别导入。

## 怎么选

- **只要识字**：本体 + OCR 包。
- **日常游戏字幕**：本体 + **PLaMo 包**，选「效率」Q4_K_M。
- **机器内存/显存小**：PLaMo 包，选「极速」Q2_K。
- **多语种、长文本、质量优先**：本体 + Pro 包，选「标准」HyMT1.5。

| 档位 | 大小 | 预计占用 | 优点 | 缺点 |
|---|---:|---:|---|---|
| 标准 HyMT1.5 | 1080 MB | 约 2.0 GB | 语种最全、长句最稳 | 最大、最慢 |
| 效率 PLaMo Q4 | 546 MB | 约 1.0 GB | 专用翻译，质量和速度平衡最好 | 比 Q2 略大 |
| 极速 PLaMo Q2 | 391 MB | 约 0.8 GB | 最小、低配友好 | 量化更低，部分句子略差 |

## 模型释放

- 普通翻译：超过设置的空闲时间自动释放；填 0 表示不自动释放。
- 游戏模式：模型常驻，关闭游戏模式或切换模型时释放。

## 安装

1. 解压本体到任意目录；
2. 打开 `QRSnap.exe`；
3. 设置 → 识别引擎 / 翻译 → 导入模型包；
4. 选对应 zip，不用手动解压。

## 使用

- `Ctrl+Alt+D`：识码
- `Ctrl+Alt+X`：识字
- `Ctrl+Alt+F`：截图翻译
- `Ctrl+Alt+G`：显示/隐藏译文

游戏模式：

1. 设置 → 游戏专属配置；
2. 开启游戏模式；
3. 添加固定字幕区域；
4. 按 `Ctrl+Alt+F` 手动翻译一次。

## 系统要求

- Windows 10 21H2 / Windows 11，64 位；
- .NET Framework 4.8；
- WebView2 Runtime 缺失时，运行本体里的 `MicrosoftEdgeWebview2Setup.exe`；
- 有 Vulkan 显卡会自动用 GPU，没有则回 CPU；
- 游戏建议无边框窗口。
