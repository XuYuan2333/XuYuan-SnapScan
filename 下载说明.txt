XuYuan-SnapScan 下载与使用

Windows 截图 OCR / 翻译工具：二维码、文字识别、截图翻译、固定区域游戏字幕翻译。

一、下载哪个文件

发布包在 GitHub Releases：
https://github.com/XuYuan2333/XuYuan-SnapScan/releases

Gitee 仓库同步源码和 tag；Gitee 附件容量放不下 110 MB 左右的本体包，下载请用 GitHub Releases。

| 文件 | 大小 | 内容 | 下载后怎么用 |
|---|---:|---|---|
| SnapScan-v1.4.17-Body.zip | 110.4 MB | 本体 + 微信 OCR + RapidOCR + 运行库 + WebView2 引导 | 解压到任意目录，运行 QRSnap.exe；只识字的话下这个就够 |
| SnapScan-Model-OCR-v1.4.1.zip | 35.9 MB | 微信 OCR + RapidOCR 模型备份 | 本体已内置；只有模型目录丢失时才需要在「设置 → 识别引擎」导入 |
| SnapScan-Model-PLaMo3-Translate-0.8B-Q4_K_M-v1.4.2.zip | 573 MB | 效率档 PLaMo Q4_K_M | 「设置 → 翻译 → 导入模型包」，档位选「效率」 |
| SnapScan-Model-PLaMo3-Translate-0.8B-Q2_K-v1.4.2.zip | 410 MB | 极速档 PLaMo Q2_K | 「设置 → 翻译 → 导入模型包」，档位选「极速」 |
| SnapScan-Model-Pro-HyMT1.5-1.8B-v1.4.1.zip | 1.1 GB | 标准档 HyMT1.5 1.8B | 「设置 → 翻译 → 导入模型包」，档位选「标准」 |

只要识字、不翻译：只下本体，解压就能用。
日常游戏字幕：下本体，再按机器配置选一个翻译包。

二、安装

1. 把本体 zip 解压到任意目录；
2. 打开 QRSnap.exe；
3. 需要翻译时，进入「设置 → 翻译 → 导入模型包」；
4. 选中对应 zip，程序会自动导入，不用手动解压到模型目录。

三、使用

热键：

- Ctrl+Alt+D：截图识码
- Ctrl+Alt+X：截图识字
- Ctrl+Alt+F：截图翻译
- Ctrl+Alt+G：显示 / 隐藏译文

游戏字幕：

1. 设置 → 游戏专属配置；
2. 添加固定字幕区域，框住游戏字幕；
3. 开启游戏模式；
4. 用 Ctrl+Alt+T 开关翻译。

手动模式按一次翻译一次；自适应模式在新字幕出现时自动翻译。游戏模式的翻译档位和遮罩模式跟随「设置」页，不在游戏页单独配置。

四、翻译档怎么选

| 档位 | 模型 | 文件大小 | 预计占用 | 适合 |
|---|---|---:|---:|---|
| 标准 | HyMT1.5 1.8B | 1080 MB | 约 2.0 GB | 多语种、长句、质量优先 |
| 效率 | PLaMo 3 Translate 0.8B Q4_K_M | 546 MB | 约 1.0 GB | 日常游戏字幕，速度和质量平衡 |
| 极速 | PLaMo 3 Translate 0.8B Q2_K | 391 MB | 约 0.8 GB | 内存 / 显存紧张、低配机器 |

普通翻译超过设置的空闲时间会自动释放模型；游戏模式模型常驻，关闭游戏模式或切换模型时释放。

五、系统要求

- Windows 10 21H2 / Windows 11，64 位；
- .NET Framework 4.8；
- WebView2 Runtime 缺失时，运行本体里的 MicrosoftEdgeWebview2Setup.exe；
- 有 Vulkan 显卡会自动用 GPU，没有则回 CPU；
- 游戏建议用无边框窗口。
