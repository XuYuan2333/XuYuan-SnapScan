翻译模式
标准：只用 Hy-MT1.5 大模型，所有语种一个模型直连，速度慢一点但最稳。
效率：英文自动走 en-zh、日文自动走 ja-zh 小模型，其他语种仍走大模型。
游戏：只用两个小模型，只支持英文 / 日文翻译成中文，大模型完全不参与。
翻译模型（三件套）
三个模型缺一不可：多语种大模型负责其他语种，en-zh / ja-zh 两个小模型负责英、日快翻。少任何一个，翻译功能整体置灰——所以不提供切换模型的选项，装齐就能用。
支持只含一个 .gguf 的 zip（Hy-MT1.5），也支持 en-zh / ja-zh 这种目录包（带 encoder + decoder + tokenizer.json）。模型包从 GitHub 发布页分别下载，导入后自动放到「MT Model」。
翻译性能
后台无感只用约 1/8 线程并降到低优先级，翻得慢但不抢前台；均衡约 1/3；性能约 1/2；全力以赴吃满所有核，最快但会短时抢占 CPU。改档位后下次翻译生效。
内存释放
超过这么多秒没有再次翻译，就把翻译服务整个退出，内存立刻还回去，只留本体这点基础占用；填 0 表示常驻不释放。改完立即生效。
译文遮罩
效率：秒出结果，原文被半透明遮罩块盖住，放大看得到块边。
拟真：把原文笔画擦掉、按周围背景补洞，再把译文按原框大小画回去，简单到中等背景下放大基本看不出替换痕迹；背景很花时会露痕，那就切回效率。
