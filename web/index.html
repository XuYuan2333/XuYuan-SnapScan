翻译模式
标准：HyMT1.5全语种模型，所有语种，按需加载，空闲 60 秒释放。
效率：Qwen2.5-0.5B 短句/游戏字幕模型，常驻（约 0.4–0.6 GB 显存/内存），切档或退出释放。
AI 接管：不占用本地显存，走云端。
翻译模型（按档位）
按档位取模型：标准要 HyMT1.5 全语种模型；效率要 Qwen2.5-0.5B 短句模型。缺哪个只影响对应档位，不再整体禁用。
只支持含 .gguf 单文件的模型包（HyMT1.5 1.8B / Qwen2.5-0.5B）。en-zh / ja-zh 目录包已不再支持。模型包从 GitHub 发布页分别下载，导入后自动放到「MT Model」。
译文遮罩
效率：秒出结果，原文被半透明遮罩块盖住，放大看得到块边。
拟真：把原文笔画擦掉、按周围背景补洞，再把译文按原框大小画回去，简单到中等背景下放大基本看不出替换痕迹；背景很花时会露痕，那就切回效率。

拖上面的滑杆，彩虹底图上那块遮罩会跟着变淡变实，所见即所得（100% 完全不透明，原字彻底看不到；越低越透出原文）。
这一组都是「跑得快不快、占多少资源」的开关：GPU 加速、CPU 线程档位、空闲释放、重复截图缓存。
GPU 加速
检测到 llama-vulkan 运行时就用显卡跑 GGUF，AMD / NVIDIA / Intel 都支持；初始化失败自动回 CPU，不会让翻译整体失败。标准 / 效率两档都走 GGUF。改完下次翻译生效。
翻译性能（CPU）
后台无感只用约 1/8 线程并降到低优先级，翻得慢但不抢前台；均衡约 1/3；性能约 1/2；全力以赴吃满所有核，最快但会短时抢占 CPU。只影响 CPU 侧；改档位后下次翻译生效。
内存释放（标准档）
只对标准档的 1.8B 生效：超过这么多秒没有再次翻译就退出服务，内存/显存还回去；填 0 表示常驻。效率档的 0.5B 是常驻模型，不参与这个计时，切档或退出软件时才释放；AI 接管不占本地模型。
截图缓存
同一屏（允许轻微差异）再翻一次直接贴上次成品，不再 OCR / 翻译；引擎、翻译模式、GPU 等设置变化后自动隔离。缓存目录在程序当前文件夹的 shotcache。
透明度越低，背景图透出越多；毛玻璃强度越高，背景越糊。
