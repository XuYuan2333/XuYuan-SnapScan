只读取本软件自己的「OCR Model」目录；灰掉的是该目录里没找到模型的。
模型包（.zip）不用自己解压挪目录，点「导入模型包」选一下就行；包从 GitHub 发布页手动下。
翻译模型
翻译模型放在「MT Model」目录，一个 .gguf 就够。当前用的是混元 Hy-MT1.5-1.8B（Q4_K_M，约 1.08 GB）：英→中 / 日→中 / 俄→中 最稳，其余 30 种语言也能直连，不用按语言对分文件夹。
支持只含一个 .gguf 的 zip（如 Hy-MT1.5），或旧式 en-zh 目录包（带 model.json / encoder+decoder）。模型包从 GitHub 发布页手动下，不用单独开关：扫到模型就能用，没有模型整块自动置灰。
目标语言
混元翻译模型一个文件就能直接翻 33 种语言，英→中 / 日→中 / 俄→中 都是直连，不用中转。
翻译性能
后台无感只用约 1/8 线程并降到低优先级，翻得慢但不抢前台；均衡约 1/3；性能约 1/2；全力以赴吃满所有核，最快但会短时抢占 CPU。改档位后下次翻译生效。
内存释放
超过这么多秒没有再次翻译，就把翻译服务整个退出，内存立刻还回去，只留本体这点基础占用；填 0 表示常驻不释放。改完立即生效。
