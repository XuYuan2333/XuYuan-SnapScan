# 下载说明 · XuYuan-SnapScan v1.4.0

本体带完整运行环境，模型按需导入。**光下本体不会翻译，也不会识字；导入哪个包，就启用对应功能。**

## 四个包

| 文件 | 大小 | 作用 |
|---|---|---|
| `SnapScan-v1.4.0-Body.zip` | 约 70 MB | 本体 + ONNX Runtime + CPU/GPU llama + VC++ 运行库 + WebView2 引导 |
| `SnapScan-Model-OCR-v1.4.0.zip` | 约 27 MB | 微信 OCR + PP-OCR 极速，导入后识字可用 |
| `SnapScan-Model-Lite-Qwen2.5-0.5B-Q2K-v1.4.0.zip` | 约 310 MB | 效率档（Qwen2.5-0.5B，英/日短句），导入后效率档可用 |
| `SnapScan-Model-Pro-HyMT1.5-1.8B-v1.4.0.zip` | 约 1.06 GB | 标准档（HyMT1.5 1.8B，所有语种），导入后标准档可用 |

## 装法

1. 解压 `SnapScan-v1.4.0-Body.zip` 到任意目录；
2. 打开 `QRSnap.exe`；
3. 设置 → 识别引擎 / 翻译 → 导入模型包，选对应 zip（不用解压）；
4. 只导入其中一个也能用对应功能：
   - 只导入 OCR：识字可用；
   - 只导入 Lite：效率档翻译可用；
   - 只导入 Pro：标准档翻译可用。

导入 Lite / Pro 会自动切到对应翻译档，不用再手动改。

## 系统要求

- Windows 10 21H2 / Windows 11，64 位；
- 本体已带 ONNX Runtime、CPU llama、Vulkan llama、VC++ 运行库；
- WebView2 Runtime 是界面必需项：如果启动提示缺少，请先运行本体目录里的 `MicrosoftEdgeWebview2Setup.exe`；
- 建议 .NET Framework 4.8（Win10 21H2 / Win11 一般自带）；
- 有 Vulkan 显卡驱动会自动用 GPU，没有则回 CPU。

## 注意

- 不再支持 `en-zh` / `ja-zh` 目录型模型包，只支持 `.gguf` 单文件；
- 截图管理员窗口需要以管理员身份运行；
- 独占全屏游戏可能截到黑屏，建议无边框窗口；
- 首次运行若被 SmartScreen 拦截，选择“更多信息 → 仍要运行”。
